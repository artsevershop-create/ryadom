Панорамы местности для демо (реальный вид вокруг стадиона и арены).
Положите сюда равнопрямоугольную (equirectangular) панораму 360x180, JPG, ширина 4096-8192 px:
  stadium.jpg  - вид вокруг стадиона (горизонт посередине кадра)
  arena.jpg    - вид вокруг арены (виден при отдалении «Здание»)
Если файла нет, демо показывает прежнее условное небо. Для проверки без публикации: stadium.html?pano=адрес.jpg ,
поворот панорамы: ?panoRot=0.25 (доля оборота). Фото должно быть вашим или со свободной лицензией.
