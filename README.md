# РЯДом: 3D-зал, который продаёт

Сайт продукта «РЯДом»: 3D-схема зала для продажи билетов (вид из кресла, выбор места, ближайший вход, оплата поверх билетной системы).

- `index.html` — лендинг (статический, без сборки)
- `demo/yamal.html` — рабочее демо концертного зала Ямальской филармонии (three.js, 686 мест)
- `img2/` — кадры демо

Контакты и реквизиты на странице оставлены заглушками в квадратных скобках.
Оплата и занятость мест в демо условные, деньги не списываются.
